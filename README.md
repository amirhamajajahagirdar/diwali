# Personal Diwali greeting

1. Edit `config.js`: change `sender`, then add one entry per friend under `friends`. The object key is the friend's link ID; `name` and `message` are their personalised greeting.
2. Create a GitHub repository and upload all four files in this folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
4. Your link will look like `https://your-username.github.io/diwali-greeting/`.
5. Share a unique greeting such as `https://your-username.github.io/diwali-greeting/?to=priya`. An unsaved name, for example `?to=Ravi`, shows the general message and greets Ravi by name.
